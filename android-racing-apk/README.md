# ALLCOINS Drag Racing для Android

Это отдельное автономное Android-приложение для дрэг-рейсинга, а не оболочка игры «Дурак» и не переход в Telegram.

## Сборка

Workflow `.github/workflows/fetch-vaz-model.yml` получает сохранённую GLB-модель ВАЗ-2107 с публичного read-only endpoint гоночного сервера Amvera, проверяет заголовок GLB 2.0 и добавляет модель в APK как локальный ресурс:

- `assets/racing/vaz-2107.glb`
- `assets/racing/model-info.json`

Внутри APK находятся локальная гоночная сцена, Three.js, GLTFLoader и модель. При запуске игра должна загружать машину из APK, а не строить временную геометрическую замену.

## Проверка

Сборка проверяет наличие обоих файлов модели внутри APK, длину GLB и заголовок формата. Затем `apksigner` проверяет подпись APK. Если endpoint не отдаёт файл или проверка модели не проходит, workflow завершается ошибкой и APK не публикуется.
